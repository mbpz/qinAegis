# QinAegis 产品与领域上下文入口

更新：2026-11-16。唯一项目记忆入口：[CONTEXT.md](../../CONTEXT.md)。完整方案：[local-web.md](../plans/local-web.md)；当前实现与验收：[开发进度](../progress/local-web-2.0.md)；阶段导航：[2.0 Roadmap](../../qinAegis-platform-roadmap.md)。

产品核心是可跨项目复用、维护、修改和人工纠正的契约。发布版本与历史执行依据不可原地改写；项目绑定承接环境差异。模型只提出草案或修订建议，不能为通过测试擅自放宽断言。

2.0 采用轻量本地 HTTP 服务和浏览器 Web 工作台，启动后请求打开浏览器，不再打包桌面客户端。Web 交互统一采用 beUI 免费组件。核心职责与依赖解耦：契约、项目绑定、模型适配/路由、执行器、场景编排、生命周期和报告分别演进，能力按真实场景组合，调序遵守依赖、权限和副作用限制。

视觉驱动测试保留 **Playwright + Midscene.js**，当前报告使用官方 **Allure 3.33.0**。模型接入目标是可扩展、可切换；现有兼容 Chat Completions 适配器和任务路由不表示已验证任意厂商、协议或视觉模型。远程模型接收页面内容或截图须遵守项目数据授权。

用户已授权分阶段开发，完整 2.0 尚未全部完成。自动运行时安装/修复、完整场景编排、持久任务/恢复、真实双项目视觉与跨平台干净安装仍有缺口。无障碍电脑控制为可选规划，须明确授权并实测，不因产品要求而默认获得系统权限。

CI 候选归档、PR 官网预览、生产 Pages、稳定 Release 与 Homebrew 发布分别核验。历史桌面客户端、TUI、固定模型/其它引擎、Notion 存储或 Homebrew Cask 描述不是当前产品事实。开始任务前先读产品记忆，再核对实际源码与验证证据，不能以历史报告或文件存在推断能力已完成。
