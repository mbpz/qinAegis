# Windows 用户级安装（I01）

日期：2026-11-18。实现已加入，真实 Windows 回归必须通过后再关闭 I01。

## 实现范围

`scripts/install.ps1` 仅使用 Windows PowerShell 5.1 和系统 .NET，默认安装到 `%LOCALAPPDATA%\QinAegis`。默认启动新服务并打开 Web 工作台；`-NoStart` 可仅安装。无需管理员权限，不修改系统 PATH、执行策略、开机启动、浏览器设置或数据目录。调用方可为当前脚本进程显式选择执行策略，脚本不持久修改策略。

在线安装固定查询 `mbpz/qinAegis` 指定 `v2.x.y` 资产和 SHA256SUMS；不会使用旧版本 latest。离线使用 `-Archive ZIP -Checksum SHA256`。HTTPS 下载仅允许明确 GitHub 资产域名、至多五次重定向；归档传输和读取上限 128 MiB、摘要文件上限 128 KiB，并限制整体读取时限。归档在同一个禁止写入/删除共享的文件句柄上先检查大小，再计算摘要和读取 ZIP，避免校验与读取间换包。摘要匹配后检查 ZIP 恰好包含三个普通成员：qinaegis.exe、LICENSE、release.json；拒绝额外/重复/链接成员、路径穿越、超限归档/文件、非对应平台/版本清单。仅提取固定二进制成员，不使用任意归档路径。

维护前检查路径祖先和内容，拒绝 reparse point、未知文件与未经安装收据核对的旧二进制；通过 OS 进程路径检查运行中的当前或备份程序，不运行未知旧程序。安装目录持有独占文件锁，Windows 原子 File.Replace 保留上一版；再次升级须显式 `-DiscardPrevious`。收据在替换前保存允许的确切二进制 SHA，替换中断后仍能辨认旧/新版。`-Rollback -NoStart` 交换两个已验证版本。`-Uninstall` 仅删除已验证的程序及收据，始终保留项目、模型、运行时和报告数据；不提供隐含删除用户数据的选项。

## 恢复边界

正常错误会移除本次 staging/download 文件，并保留原始异常。系统断电或进程强杀可能留下 `.stage-*` / `.swap-*`；下一次维护会拒绝未知内容，用户必须先核对并移出残留，不能按文件名前缀自动删除。原子替换后当前程序仍可启动；回滚交换被强杀时可能需要人工将验证过的 swap 作为备份恢复。不能据此宣称已完成全部断电恢复或签名验收。运行状态检查和实际替换之间的竞态最终由 Windows 正在执行文件的写入限制拒绝；不能停止别的进程以强制升级。

## 验证

`scripts/test-windows-install.py BINARY` 必须在 Windows 上运行，显式拒绝其他系统。使用真实构建程序，临时带空格目录，隔离服务状态和用户数据，离线检查 SHA/ZIP/链接/清单拒绝、未知文件保留、真实后台服务运行拒绝覆盖、可运行 PE 尾部 fixture 升级、双向回滚和卸载保留数据。第二份二进制的新增字节明确为验收 fixture，不代表发布第二个版本。CI 不打开浏览器；默认自动打开仍需 Windows 桌面验收。

macOS 本地只完成 Python 语法检查，不能替代 PowerShell 解析及 Windows 行为。签名、干净桌面电脑、在线稳定资产下载和强杀恢复仍在 I02/I03 等整体验收项内。
