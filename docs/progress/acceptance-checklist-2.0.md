## 1. 真实契约与模型验收准备

- [x] M01：项目模型路由覆盖全局默认；作用域/修订冲突、缺失路由、能力及远程数据授权在服务端校验，已启动任务保持快照。
- [x] M02：Web 可对已保存模型执行有超时的合成文本/结构化输出检测；分别显示声明与观测，不将连通性当作视觉兼容。
- [ ] M03：生成/纠正记录实际调用的模型与备用原因；失败与业务断言区分，密钥不进入事实、日志或导出。
- [ ] M04：步骤级模型选择与预先批准的降级策略接入版本化流程；不能临时绕过能力或授权要求。依赖 F03/F04。
- [ ] M05：增加至少一种独立模型协议适配器并验证错误/配额/超时/输出兼容，不能只改 provider 标签。
- [ ] M06：锁定 Midscene 版本的实际视觉兼容检测；不兼容明确拒绝，不静默改模型或 family。
- [ ] V01：两个经授权的真实项目复用同一发布契约；核对业务原始断言、绑定差异、截图、实际模型与 Allure。
- [ ] V02：真实项目验证纠正/派生/弃用/选择迁移，新版本仅影响选中引用，旧运行仍可还原。

外部条件：用户于 2026-11-17 确认暂时没有真实项目与视觉模型配置。M06/V01/V02 保留待验收；不得将本机 fixture、示例站点或 CI 绿色计为真实业务通过。

## 2. 运行时交付（P4，供后续执行与安装验收使用）

- [x] R01：独立执行器运行时可复现构建；包含编译 JS、锁定生产依赖、来源/版本清单和相应 Node，不依赖源码/tsx/开发依赖。
- [x] R02：Web 环境页检测运行时、Node、Playwright/Midscene/Allure 版本、浏览器存在及实际启动，错误有明确修复建议。
- [ ] R03：按需下载/导入运行时，校验来源与 SHA-256、归档路径/大小/符号链接；暂存后验证、原子切换，失败保留旧版本。
- [ ] R04：Web 显式安装所需浏览器，任务显示进度/失败并可取消；不自行提权安装系统组件。
- [ ] R05：运行时升级/回滚不影响活动任务；离线仍能管理资产及查看已有报告。
- [ ] R06：在没有源码、全局 Node 或开发工具的干净环境完成浏览器/官方 Allure 执行；逐平台留证。

## 3. 配置与数据可靠性（P3）

- [x] D01：配置有私有权限、有界读取、进程间写锁、原子替换；写入或校验失败保留旧文件。
- [x] D02：修改前备份；Web 可查看备份元信息、显式恢复，拒绝坏备份/越界路径/过期确认；恢复前保留现状。
- [x] D03：多标签配置保存有修订检查；原值为空/清除密钥语义保留，已启动任务不受新配置影响。
- [ ] D04：旧格式/多来源配置迁移提供预览、摘要和人工选择；重复迁移幂等，失败可恢复，不自动合并秘密。
- [x] D05：用例编辑和状态跨路径移动具备崩溃恢复；不出现静默丢失、重复身份或部分来源。
- [ ] D06：报告生成中断残留可诊断/清理，不改写既有 run.json 或已完成报告。

## 4. 任务生命周期（P5，依赖稳定存储与运行时）

- [x] T01：任务 ID 不因重启重用；任务摘要/状态/安全快照持久化，终态仅写一次。
- [x] T02：重启将遗留活动任务标记 interrupted；保留日志/证据，不自动重放有副作用的动作。
- [x] T03：任务列表及增量日志（cursor/截断提示）可刷新恢复，内存和磁盘增长有明确上限。
- [ ] T04：取消传播到长模型/引擎调用及受管进程树；停止真实退出后才完成，取消/完成竞争有回归。
- [ ] T05：有界队列及项目/浏览器/桌面资源互斥；拒绝或排队原因可见，任务提交及时返回。
- [ ] T06：浏览器任务隔离 profile、端口与工作目录；只回收本服务拥有的资源。

## 5. 业务与场景编排（P6，依赖 R/D/T）

- [ ] F01：Web 受控规格创建/读取/编辑及项目关联；无任意本机路径入口，缺失/冲突/超限均可恢复。
- [x] F02：用例内容编辑/差异/审核失效与重新批准闭环；修改脚本不能沿用旧批准状态。
- [ ] F03：流程草稿/校验/不可变版本与执行计划快照；依赖、端口类型、能力、权限和非幂等副作用校验。
- [ ] F04：运行编排支持类型化输入输出、条件、等待、超时、有界重试与失败清理；原始业务断言不可自动放宽。
- [ ] F05：Web 可组合并合法调序，已有有效用例可直接执行；缺前置条件明确拒绝。
- [ ] F06：无模型、空项目、坏规格、模型限流、部分执行失败、取消、刷新/重启等用户旅程端到端验证。
- [ ] F07：性能/压测能力按实际 runner 检测依赖并执行；缺指标/未运行不能显示通过。
- [ ] F08：Allure 跨次历史/趋势单列后续增强；当前单次报告的边界保持明确，不阻塞本次基础 GA。

## 6. 可选桌面无障碍试点（单独范围，不阻塞未启用的基础服务）

- [ ] A04：实测最小真实场景，再决定平台/动作发布范围；其他系统未验证时明确不支持。
